# 假阳性审计设计（2026-10-29）

模式：design（先导诊断实验，非发表主实验）
场合与假设：桥梁 CODEBRIM 裁块；主张来自 idea-card.md 的核心洞见。

## 要回答的问题
H1：在桥梁正常图上，现有"偏离参考"类检测器的假阳性面积，主要落在可命名的良性干扰上，而不是连续低层变异上。
H2（次要）：可命名干扰相对正常参考的偏离幅度不小于低层变异（否则"统计擦除原理上处理不了"的论证不成立）。
H3（次要）：正常图标签噪声（未标注的真实缺陷）占比可控。

## 预注册决策规则（审计前冻结）
令 share_A = 类别 A 的假阳性面积 / (A+B+C+E 总面积)，D 单独统计。
- 两个被审计模型的 share_A 均 ≥ 0.50 → 维持主路线。
- 任一模型 share_B ≥ 0.50 → 转备用路线（统计擦除 vs 语义锚定的诊断研究）。
- 其余（A、B 均在 0.30–0.50）→ 维持主路线，但 P3 互补性预测升为核心主张。
- D ≥ 0.15 → 先清洗正常图标签，再重跑审计。
- H2 检验：A 类块的平均残差分 ≥ B 类块；若显著低于，洞见第二段需改写。

## 被审计模型（均不在自建集上训练）
| 模型 | 代表什么 | 配置 | 来源 |
|---|---|---|---|
| AdaptCLIP 官方权重 | CLIP 系 + 参考残差 | ViT-L/14@336，518 输入；zero-shot 与 4-shot 各一套图；4-shot 参考从训练集正常图随机抽 4 张，固定种子 | github.com/gaobb/AdaptCLIP |
| AnomalyDINO | 纯视觉残差（训练免费） | DINOv2-B/14，参考 = 训练集正常图随机 16 张，patch 最近邻距离 | github.com/dammsi/AnomalyDINO |
| IDEAL（可选） | 统计擦除 | 若 mala-lab/IDEAL 代码可跑：正常参考 16 张 + 异常参考每类 4 张（来自训练集） | arXiv 2605.23231 |

AdaptCLIP 与 AnomalyDINO 为必做；IDEAL 能跑则加，直接服务 H2 与 P3。

## 数据
- 审计图像：验证集正常图 277 张（不动测试集）。
- 阈值标定：验证集异常图 123 张。
- 参考图：训练集正常图。

## 阈值
每个模型独立标定：在验证集异常图上取像素级 TPR = 95% 对应的阈值（与 FPR@95TPR 约定一致）。同时记录该阈值下验证集异常图的像素 FPR 作参考。不使用各模型论文的默认阈值。

## 假阳性块的提取与抽样
1. 对每张正常图的异常图做阈值二值化，取 8 连通块，丢弃面积 < 64 px（512² 下约 0.02%）的块。
2. 记录每块：图像名、面积、包围框、块内平均分、块内最大分。
3. 抽样：每个模型按面积三分位分层，每层 40 块，共 120 块/模型；三个模型最多 360 块。面积分层是为了让面积占比估计不被大量小块主导。
4. 导出每块的标注卡：原图 + 块轮廓叠加 + 局部放大（块包围框外扩 32 px），文件名含块 ID。

## 标注分类体系（冻结）
A 可命名良性干扰：A1 水渍/湿斑；A2 阴影/光照边界；A3 苔藓/生物附着（薄层）；A4 修补/砂浆填充；A5 涂鸦/油漆；A6 模板纹理/施工缝/构件边缘；A7 污垢/烟熏。
B 连续低层变异：B1 骨料/表面纹理颗粒；B2 平滑光照渐变/曝光；B3 模糊/噪声/压缩伪影。
C 非表面区域：C1 背景物体（天空、构件外植被、线缆）；C2 裁块边界/填充。
D 疑似真实缺陷（正常图标签噪声）：D1 疑似四类之一；D2 疑似其他缺陷。
E 无法判断。

每块只选一个主类别；若块跨两类，按面积大者。标注者为用户本人；随机抽 20% 块在一周后盲重标，报告自一致率。

## 统计输出
- 表 1：每模型 × 类别的块数占比与面积占比（面积占比用分层权重还原）。
- 表 2：每模型 A、B、C、D、E 的汇总面积占比，附决策规则判定。
- 表 3（H2）：每模型 A 类与 B 类块的平均分、最大分及差值。
- 图 1：每模型的假阳性面积占比堆叠条形图（类别 A–E），作为论文动机图候选。
- 图 2：每类别 2–3 个代表块示例。

## 脚本用法（audit_fp.py，已用合成数据自检全流程）
依赖：numpy、pillow、scipy、matplotlib。每个模型先把验证集 400 张图的异常图存为 `<maps_dir>/<图名>.npy`（float，512×512）。

```bash
python audit_fp.py threshold --model adaptclip_zs --maps maps/adaptclip_zs --masks val/masks_union --anomaly-list val/anomaly.txt --out audit/adaptclip_zs
python audit_fp.py extract   --model adaptclip_zs --maps maps/adaptclip_zs --normal-list val/normal.txt --out audit/adaptclip_zs
python audit_fp.py sample    --per-stratum 40 --out audit/adaptclip_zs
python audit_fp.py export    --maps maps/adaptclip_zs --images val/images --out audit/adaptclip_zs
# 人工在 audit/<model>/sample.csv 的 label 列填 A1–E，对照 cards/ 目录的标注卡
python audit_fp.py summarize --samples audit/adaptclip_zs/sample.csv audit/adaptclip_4s/sample.csv audit/anomalydino/sample.csv --out audit/summary
```

`masks_union` 为四类掩码的并集二值图（>0 为缺陷）。summarize 会按预注册规则直接给出每个模型的判定，并输出 fig1-fp-share.png。

## 协议修正 1（2026-10-31，标注开始前）
在服务器 runs/audit 上按原协议（TPR = 95%）提取后发现，三个被审计模型在该工作点把正常图的 65%–77% 面积标为异常（adaptclip_zs 0.685，adaptclip_4s 0.653，anomalydino 0.766），最大连通块等于整图，块级分类失去意义。该工作点对未在目标域训练的模型过松。

修正：阈值标定改为验证集异常图像素级 TPR = 50%。该工作点下正常图被标面积为 12%–19%（adaptclip_zs 0.123，adaptclip_4s 0.126，anomalydino 0.185），块可辨识。各工作点的完整数字见 runs/audit/*/tpr95 归档旁的本节记录：

| 模型 | TPR95 正常面积 | TPR80 | TPR50 | bgFPR5% 时 TPR |
|---|---|---|---|---|
| adaptclip_zs | 0.685 | 0.370 | 0.123 | 0.241 |
| adaptclip_4s | 0.653 | 0.365 | 0.126 | 0.177 |
| anomalydino | 0.766 | 0.441 | 0.185 | 0.010 |

修正时三个模型的 sample.csv 标注列均为空，决策规则与分类体系不变。TPR95 的 threshold / blobs / sample / cards 归档到 runs/audit/<model>/tpr95/ 以备查。

## 协议修正 2（2026-10-31）：取消人工标注，改为无标注前提检验
用户决定不做人工标注。A–E 分类与 share_A 决策规则停用；已生成的标注卡保留但不填。前提检验改为下面的无标注实验，它只回答 H2 的推论"统计擦除是否足以消除桥梁假阳性"，不再回答"假阳性是否可命名"。

### 无标注前提检验：统计擦除充分性
- 对象：同一批验证集正常图与三个未在目标域训练的模型（adaptclip_zs、adaptclip_4s、anomalydino）。
- 操作：在各模型的 patch 残差上实现 IDEAL 式 Normal Variation Eraser（对每个查询 patch 取最近 12 个正常参考 patch 做 PCA 取 4 维子空间，残差在子空间内的分量乘 0.8；另跑完全投影即乘 0 的强版本）。不使用任何文本。
- 度量：固定 TPR = 50% 工作点（擦除前后各自重标定），比较正常图被标面积与异常图背景 FPR；同时报告像素级 P-AP / P-AUROC 变化，确认擦除没有同时损失召回。
- 判定（审计前冻结）：
  - 擦除后正常图被标面积下降 ≥ 50%（相对值）→ 统计擦除基本够用，语义锚点只能作为增量，贡献 1 的措辞改为"互补"。
  - 下降 < 25% → 统计擦除不足，支持"桥梁假阳性主要是大幅度、参考外的偏离"，主路线成立。
  - 其间 → 主路线保留，P3 互补性升为核心主张。
- 成本：仅推理，GPU 约 1 小时，无人工。

### 失去的东西（需在论文中承认）
- 不能给出"假阳性 X% 是水渍/阴影"这类按类别的动机图；动机改为"统计擦除后假阳性仍剩 Y%"。
- P2 锚点特异性与 P3 增益分解无法按干扰类别拆分，改为聚合版本：删除全部干扰锚点 vs 保留，看正常图 FPR 总量变化；语义锚点与擦除叠加 vs 各自单独。
- P1 参考外干扰子集无法按类别构造，改为"按全局特征把验证集正常图与检索库做 k-means 分簇，留出整簇"的无标注近似。
- 干扰锚点的可解释性改为定性图：在正常图假阳性区域上可视化各锚点的 π 响应，由读者直接看。

### 实现记录（2026-10-31）
脚本 `erasure_check.py`（已同步到服务器仓库根目录）。与设计的对应与偏差：
- 检测器不再是 AdaptCLIP 官方头，而是两个冻结骨干上的纯 patch 最近邻残差：DINOv2-B/14 最后一层；CLIP ViT-L/14@336（DPAM 20）层 6/12/18/24 取均值。原因：擦除作用在残差上，纯残差检测器才能把"擦除是否足够"与"学习头是否补偿"分开。AdaptCLIP 的 PQ adapter 消费的正是这些 CLIP 层特征。
- 参考固定为 runs/audit/anomalydino/references.json 的 16 张训练集正常图（种子 10），两个骨干共用。
- 特征 L2 归一化后用欧氏距离；最近 12 个正常 patch 做中心化 SVD 取前 4 个右奇异向量；alpha ∈ {1.0, 0.8, 0.0}。
- 每个 alpha 独立在异常图上重标定 TPR = 50% 阈值。擦除会同时压低缺陷区域的残差，所以阈值下移，正常图被标面积可能不降反升；这种情况按"下降 < 25%"判定。
- 像素级 AUROC / AP 用 100 万正、100 万负像素的固定种子子采样，仅作诊断。
- 烟雾测试（6 张图）两骨干均跑通；全量 400 张在 runs/erasure/<backbone>/ 下，console.log 记录进度。

### 结果（2026-10-31，验证集 277 正常 / 123 异常，TPR = 50%）
| 骨干 | alpha | 正常图被标面积 | 相对 alpha=1 变化 | 异常图背景 FPR | P-AUROC(子采样) | P-AP(子采样) |
|---|---|---|---|---|---|---|
| DINOv2-B/14 | 1.0 | 0.185 | 0 | 0.266 | 0.709 | 0.640 |
| DINOv2-B/14 | 0.8 | 0.191 | +2.9% | 0.276 | 0.706 | 0.632 |
| DINOv2-B/14 | 0.0 | 0.216 | +16.6% | 0.315 | 0.689 | 0.610 |
| CLIP ViT-L/14 | 1.0 | 0.183 | 0 | 0.227 | 0.730 | 0.666 |
| CLIP ViT-L/14 | 0.8 | 0.186 | +1.8% | 0.234 | 0.727 | 0.662 |
| CLIP ViT-L/14 | 0.0 | 0.198 | +8.1% | 0.252 | 0.714 | 0.647 |

判定：两骨干、两种擦除强度下正常图被标面积均未下降，反而上升 2%–17%，像素级 AUROC / AP 同步下降。按预注册规则属"下降 < 25%"，统计擦除不足，主路线成立。

解释：擦除只能去掉残差在"最近 12 个正常 patch 张成的 4 维局部子空间"内的分量。桥梁正常图上的假阳性残差几乎不在这个子空间里，所以擦除对假阳性无效；而缺陷区域的残差有一部分在子空间内，被削弱后阈值下移，假阳性反而增多。这与洞见第一段"桥梁良性变异幅度大、不在参考附近"一致，但不直接证明这些变异可命名。

边界：
- 只检验了 IDEAL 的 NVE 部分，没有复现它在异常参考上学习的 Intrinsic Deviation Encoder；IDEAL 完整方法在桥梁上的表现仍需作为基线实际跑。
- 参考为 16 张随机训练正常图。用检索式参考（M1）会改变子空间质量，但那是在检验 M1 而非擦除本身。
- 两骨干的残差检测器在该工作点本身很弱（P-AUROC 约 0.71–0.73），说明"相对正常参考的偏离"在桥梁上离缺陷信号很远，这也是论文动机的一部分。

原始数字见 results/erasure/<backbone>/results.json（本地）与 runs/erasure/<backbone>/（服务器）。
