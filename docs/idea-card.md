# Idea 卡：面向桥梁缺陷的 AdaptCLIP 改进（2026-10-29）

## 资源与设定
- 自标注集：约 1000+ 异常图（裂缝 / 剥落 / 泛碱 / 锈蚀），正常+异常合计约 4000 张，512 px。像素级掩码标注（用户 2026-10-29 确认）。
- S2DS（Benz & Rodehorst）：743 张像素级标注，类别含 crack / spalling / corrosion / efflorescence / vegetation / control point。建议只做跨数据集测试，不参与训练。
- 可选外部测试集：dacl10k（9,920 张，12 类损伤），用于更大规模的泛化评估。

## 研究问题（2026-10-29 按审核 C5 前置）
给定一座或多座桥梁的正常表面图与四类缺陷的像素级标注，学习一个检测器，使其：
1. 在训练未见的桥梁与采集条件下（S2DS、dacl10k）保持缺陷分割能力；
2. 对训练未见的缺陷类型（空洞、植被侵入、渗水、接缝破损等）仍能给出二元检测与"未知缺陷"标签；
3. 在良性变异（水渍、阴影、修补、涂鸦、苔藓）密集的表面上保持低假阳性。

为什么走异常检测路线而非多标签分割：全监督分割网络只能输出训练过的类别，对未见类型沉默；跨桥泛化依赖大规模标注。以正常库为参照、以语言为类别接口的 AD 框架在原理上同时覆盖 1 与 2，代价是必须解决 3。本工作的贡献就落在 3 以及由 3 支撑的 2。

## 定位与贡献声明（2026-11-05 第四次改写：有监督分割定位，用户决定）

**方法是什么**：冻结 CLIP ViT-L/14 上的文本锚点引导轻量多标签缺陷分割头。约 6.6 M 可训练参数（2026-11-06 核对检查点，此前误写为 3 M），骨干不动；6 个文本锚点（正常、4 类缺陷、类无关缺陷）给出类别接口；4 路独立 sigmoid 类型头允许缺陷重叠；ν（缺陷组质量）门控类无关缺陷通道与图像级头。训练使用 CODEBRIM 917 张异常图的四类像素掩码与 1,944 张正常图，是**有监督**方法。

**方法不是什么**（实验已证伪，论文中作为诊断结果如实报告）：
- 不依赖正常库检索：域内给 1 张随机参考与检索 4 张结果相同（results.md §2h）。但与正常 patch 的残差信号本身有用：去掉残差分支后二元图 P-AP −9.7、泛碱 P-AP −12、正常图误报面积约 8 倍（§2i，单种子）。因此最终模型保留残差分支，推理只需 1 张任意正常图，不需要正常库。
- 不靠命名干扰锚点抑制误报：12 对 6 锚点三种子无差异（§2e）。
- 相对 AdaptCLIP 基线没有一致的跨数据集二元定位优势（2026-11-06 按修正真值改写，results.md §2k、§2l）：S2DS 上 P-AP 高 8.0 但 I-AUROC 低 3.2；dacl10k 上 I-AUROC 高 2.5 但 P-AP 低 7.8；P-AUPRO 在域内不占优、两个外部集上都明显更低。换目标域正常参考不改变（§2h）。
- P-AUPRO 不是强项：此前"P-AUPRO 大幅超过基线"来自并集真值漏掉裂缝与锈蚀的错误（§2k），已撤回。

**贡献**
1. 解耦的多标签类型头 + 保留局部相似度：四类独立 sigmoid 头接在逐锚点局部 / 区域混合相似度上。裂缝 P-AP 0.07 → 0.33–0.39，mAP 0.55 → 0.71；消融显示纯区域池化使裂缝 P-AP 掉到 0.08（§2f）。可学 γ 与纯局部持平，论文只主张"局部相似度必须保留"。
2. ν 门控的类无关缺陷通道与图像头：I-AUROC 88.0 → 92.3，超过在同数据上训练的官方 AdaptCLIP（91.3）；去掉后图像级 −1.1、mAP −2.8（单种子，待补种子）。
3. 评估协议与数据审计：Cleaned-Val（正常验证集 21 张含缺陷图，误报绝对值差一个数量级而排序不变）；匹配 TPR 的正常图误报度量；统计擦除充分性检验。
4. 一组可复现的负结果（Analysis & Diagnostics）：命名干扰锚点坍缩 → 惰性 → 无效；检索无增益（参考的选择与数量不影响结果，但残差信号本身有用）；相对 AdaptCLIP 基线的域内优势不跨域迁移。对在基础模型上做桥梁缺陷检测的后续工作有直接参考价值。

**全监督对照的结果（2026-11-05，results.md §2j，单种子）**：SegFormer-B2（约 25 M 参数全部可训练，同数据同掩码）。
- 域内它更强（二元数字为 §2k 修正值）：mAP 81.5 对 72.6，裂缝 P-AP 54.5 对 35.7，二元图 P-AP 88.1 对 81.8，P-F1max 84.3 对 74.7，Cleaned-Val 上 mIoU@0.3 75.1 对 59.4，正常图误报再低约 5 倍；P-AUPRO 持平（78.4 对 78.8）；本方法只在图像级（I-AUROC 92.1 对 90.1）与锈蚀上占优。
- 跨域排序反转，两个外部集一致：S2DS test 上本方法 I-AUROC 78.1 对 74.3，P-AP 70.9 对 63.0，mAP 46.6 对 32.7（P-AUPRO 41.5 对 45.7，略低）；dacl10k 严格四类子集上 I-AUROC 69.8 对 56.2，P-AP 32.8 对 22.0，mAP 16.1 对 8.6（§2l）。dacl10k 上所有模型的绝对值都很低。
- 由此的卖点表述（2026-11-06 更正）：**冻结 CLIP + 约 6.6 M 可训练参数，域内二元 P-AP 比 AdaptCLIP 基线高 20 个点并给出按类输出、图像级略好于 SegFormer-B2；跨数据集按类分割与图像级明显优于全参数训练的 SegFormer-B2。域内像素精度（尤其裂缝）与 P-AUPRO 是劣势，如实报告。** 不主张优于或接近全监督分割的域内精度。
- 裂缝对策：不重训的滑窗推理使裂缝 P-AP 35.7 → 42.3，但纯滑窗使泛碱 −25（§2m），说明尺度需求按类别不同。据此试验了把 1/4 分辨率细节支路作为第三尺度、逐锚点学混合权重（§2n）：只训支路裂缝 42.4，联合微调 37.8，都没过 44 的止损线，增益不迁移到 S2DS / dacl10k，学到的细节权重很小。细节支路不进最终模型，与滑窗一起作为"分辨率是裂缝瓶颈之一，但补上后仍差 SegFormer 12 个点"的分析实验。
- **与 CLIP 系方法的对比（2026-11-06，results.md §2o）改变了跨域卖点**：域内本方法在二元 P-AP（81.8，对 Bayes-PFL 62.4、MultiADS 56.6、AnomalyCLIP 30.7）和按类指标（mAP 72.6 对 MultiADS 64.6）上最好；但跨数据集上 MultiADS（3.1 M 线性投影 + 多类型提示）的按类分割与 P-AUPRO 都高于本方法（S2DS mAP 52.8 对 46.6，dacl10k 18.5 对 16.1，裂缝两处都高 6 到 7 点）。"跨数据集优于 SegFormer-B2"仍成立，但不能再说成本方法特有的优势。上面第 35 行的卖点表述待按此重写：可主张的只剩域内精度（对所有 CLIP 系方法）与按类输出；跨域只能说"与 MultiADS 同属冻结 CLIP 路线，优于全监督分割，但不如 MultiADS"。
- 用户决定不再补种子；SegFormer 为单种子。

## AdaptCLIP 的三个假设在桥梁场景下的失效点
1. prompt-query adapter 用"查询 patch → 最近邻正常 patch"的残差当异常信号，隐含"正常参考与查询同物同姿态"。混凝土表面无规范外观，残差被风化、光照、模板纹理、污渍主导。论文自己也报告：在姿态无关(MPDD)与噪声(KSDD)数据上 few-shot 反而不如 zero-shot。
2. 文本分支只学二元"正常/异常"。四类缺陷语义差异大，且与良性干扰（水渍、阴影、苔藓、涂鸦、修补痕）易混；二元监督会把它们塌缩到同一"异常"方向（DAPO 的动机）。
3. ViT-L/14@518 的 patch 为 14 px（37×37 网格）。裂缝宽度常 ≤ 3 px，patch 级特征先天分辨不出细线结构。

## 核心洞见（2026-10-29 按审核 C1 改写）
工业 AD 假设"偏离正常参考 ≈ 缺陷"，并且现有去变异方法（IDEAL 的 Normal Variation Eraser）假设良性变异幅度小、局部线性低维、已出现在参考附近。桥梁表面违反这三条：阴影边界、水渍、修补块、涂鸦、苔藓相对任何参考都是大幅度、离散、多模态的偏离，且参考库里未必有相似实例。在"偏离越大越异常"的打分下它们必然成为假阳性，统计擦除在原理上无法处理。

这些干扰的共同特点是可命名。首版洞见（2026-10-29）是：**在开放环境表面上，假偏离主要是离散的、可命名的现象，而不是连续的低层变异；所以应由语言而非统计来拒绝，并且这种拒绝随名称跨数据集迁移。**

### 2026-11-03 修订：实验支持了前半句，否定了后半句的实现方式
- 前半句（假偏离是离散高层现象、统计擦除无效）由擦除充分性检验支持（audit-design.md）。
- 后半句（由命名锚点来拒绝）在 CODEBRIM 上没有得到支持：四版模型里，命名干扰锚点要么坍缩成通用背景槽（v0），要么在修好坍缩后完全不被使用（v1-fix、v2），而误报改善与锚点是否被命名无关（results.md §2d.3）。原因有二：训练集里没有干扰的正监督，零样本伪标签既稀疏又有偏；CLIP 文本空间里"intact concrete"与"water stain on concrete"的余弦本就 0.75–0.87，投影后 normal 锚点轻易覆盖所有干扰锚点。
- 修订后的洞见：**假偏离需要一个独立于"正常"与"缺陷"的第三组解释槽，并且这一组只能在残差高的区域被训练；至于这一组是否带名字，在没有外部正监督时不影响结果。** 换言之，有效的是"残差条件化的三元竞争"这一结构，而不是语言。语言的作用退为事后解释。

边界：统计擦除擅长连续、无名的低层变异（骨料纹理、光照渐变）。本工作的主张收缩为"桥梁数据的假阳性主要由离散的高层偏离构成，需要在高残差区域显式建模第三组解释"。

### 首版设计（2026-10-29）
- 组件 M1 检索式正常参考（改 prompt-query adapter）：用训练集正常图建库，按特征相似度为每张查询图检索同材质同光照的参考，再做残差对齐。有先例（RAID、ReMP-AD），作为组件而非贡献点。
- 贡献 M2 语义锚点与竞争式门控（改 textual adapter 与融合规则）：
  - 锚点集合 = 4 个缺陷类型提示 + 1 个类无关缺陷提示 + 固定清单的良性干扰提示（water stain / shadow / moss / patch repair / graffiti / formwork texture，清单按巡检规范固定）。
  - 门控不是"有干扰就压掉"，而是竞争：在残差高响应区域上，缺陷类型、类无关缺陷、干扰类共同竞争解释权。阴影里的锈迹只要锈的证据在，锈通道照样赢。
  - 干扰识别在区域级而非 patch 级：先按残差取高响应连通块，对块做池化后与锚点比较。原因是 CLIP patch 级局部语义偏弱（AF-CLIP 一线的结论）。
  - 监督：缺陷锚点由掩码监督；干扰锚点只由正常图监督（正常图上所有高残差块的解释权应归干扰类或背景）；两者唯一共同约束的像素是正常图像素。
- 两者的交互：M1 给出"相对参考的变化"，M2 给出"变化的语义归属"；类无关缺陷通道 = 残差 × 竞争后非干扰的概率。

## 像素级掩码带来的训练方案（2026-10-29）
- M2 多类型分割头直接用 4 类掩码做 Focal+Dice 监督，二元异常掩码由 4 类掩码取并集得到；AdaptCLIP 原损失（图像级 CE + 像素级 Focal/Dice）可整体沿用，只把通道数从 2 改为 1+4+干扰类数。
- 干扰类（stain / shadow / moss / patch repair）在自建集里没有掩码。两种来源：(a) 正常图上所有像素视为"非缺陷"，干扰提示只以对比方式学习，不单独监督；(b) 从正常图中按 CLIP 文本相似度自动挑出高响应区域做弱伪标签。先做 (a)，(b) 作为消融。
- M1 检索库只放正常图，不需要掩码；但异常图中的缺陷掩码之外区域也可以作为"带干扰的正常 patch"加入库，预期能降低污渍类假阳性。这是一个值得单独消融的点。
- 训练 / 验证 / 测试：自建集按桥梁（或拍摄批次）划分，不按图像随机划分，否则跨桥泛化会被高估。S2DS 与 dacl10k 只做测试。
- 评估指标：图像级 AUROC / AP；像素级 AUROC、PRO、F1-max；多类型用 per-class mIoU 与 FPR@95TPR（正常图）。

### 对设计的影响
- M1 检索库：主结果只用训练集正常图（1,944 张）建库；"允许检索测试集中同原图的正常裁块"作为上界消融单列，不能混入主表。
- 正常裁块与异常裁块来自同批原图，材质与光照分布一致，对检索式参考有利；对外部测试（S2DS / dacl10k）则是分布外，这正是要展示的泛化点。
- 掩码为 RGB 编码，按图层优先级拍平（用户 2026-10-29 澄清）：裂缝 > 锈蚀 > 剥落 > 泛碱。存储的掩码每个像素只有一种颜色，重叠处只保留上层类别，下层被遮挡的部分在拍平掩码中丢失。因此：
  - 存储形态上像素互斥；但语义上存在被遮挡的重叠（最常见：剥落区内的锈蚀钢筋被标成锈蚀，剥落被扣掉）。
  - 若原始分层标注（Labelme JSON / 每层多边形 / 每类单独 PNG）仍在，应从原始层重建四通道多标签掩码，用 per-class sigmoid 训练与评估，这是首选。
  - 若只剩拍平掩码，则按单标签处理：softmax 五通道（背景 + 四类）或 sigmoid 互斥标签均可；需在论文中写明优先级规则，并承认剥落与泛碱的面积被系统性低估。优先级本身符合巡检习惯（裂缝细，置顶不会遮挡大面积类别），可以辩护。
  - 像素级指标：互斥标签下按类计算 IoU；二元异常掩码为四类并集，不受拍平影响。
  - 外部测试集对齐：S2DS 同为单标签语义分割，直接可比；dacl10k 为多标签，评估本方法时对其标注按同一优先级拍平，或只报告二元与 per-class 独立指标。
  - 数据加载前仍需统计全部掩码的唯一颜色集合，固化调色板。
- 类别映射（用户 2026-10-29 确认）：CODEBRIM 的 exposed bars 全部锈蚀，已并入"锈蚀"类。因此本数据集的"锈蚀" = 锈迹 + 外露锈蚀钢筋。
  - dacl10k 对齐：Rust 与 Exposed Rebars 两类合并映射为锈蚀；Spalling 映射为剥落；Crack、Efflorescence 一一对应；其余类（Cavity、Vegetation、Graffiti 等）作为"训练未见类型"只参与二元异常评估。
  - S2DS 对齐：其 corrosion 类是否包含外露钢筋需在 README 中核对；不一致时在论文中说明映射规则。
  - 对 M2 文本锚点的影响：锈蚀类用两条子提示（"rust stain on concrete" 与 "exposed corroded rebar"）做提示集成，共享同一输出通道；避免单条提示只覆盖其中一种外观。
  - 风险：外露钢筋在形态上更接近剥落（有材料缺失），与锈迹（平面色斑）差异大。若锈蚀类内部双峰导致 mIoU 偏低，可在消融中拆回两类对照。
- 图像级对照：CODEBRIM 原始测试集带图像级多标签，可额外报告图像级多标签指标，与 CODEBRIM 文献（MetaQNN/ENAS 系列）直接可比。

### 数据集适用性结论
规模（约 4k 裁块、1.3k 像素级异常）足以训练轻量适配器，不足以也不需要训练整骨干；正常/异常约 2:1 的比例适合同时支持正常库检索与多类型监督。主要缺口是外部测试集的类别对齐与桥梁级划分证据。

## 开放集：训练未见的缺陷类型怎么办（用户 2026-10-29 提问）
问题：若二元异常只取四类通道的 max，训练未见的缺陷（空洞、植被侵入、渗水、涂鸦、接缝破损）会被漏掉，这与『泛化』主张冲突。

机制：输出通道设计为 1 个类无关缺陷通道 + 4 个类型通道 + 若干干扰通道。
- 类无关通道 = M1 参考残差 × 区域级竞争后"非干扰"的概率（按审核 C3 明确）。训练目标是四类掩码的并集，但它学到的是『偏离且非干扰』，不是四类的外观，因此能迁移到未见类型。
  - 与 MultiADS 的区别：MultiADS 的通用异常图是文本 normal 通道相似度的补集，对未见类型依赖推理时写新提示；本通道的来源是视觉残差，不依赖任何未见类型的名称，文本只负责排除干扰。预测：在 dacl10k 未见类上，不写新提示的本通道召回 ≥ 写了新提示的 MultiADS 通用图。
  - 与 IDEAL 的区别：IDEAL 的偏离方向由异常参考学得，未见类型靠"共享偏离方向"；本通道不学偏离方向，只排除可命名干扰，对与已见类型形态差异大的未见类型（空洞 vs 锈迹）更不依赖训练分布。
- 文本侧为类无关通道配一条通用提示（damaged / deteriorated concrete surface），与四类具体提示并列；AnomalyCLIP 式的对象无关提示在这里复用。
- 决策规则：二元异常 = max(类无关通道, 四类通道)。某像素类无关通道高而四类通道都低 → 输出『未知缺陷』，这是面向巡检的开放集输出，而不是强行归入四类之一。

评估（必须有，否则开放集只是口头主张）：
- 域内 leave-one-type-out：每次用三类训练、第四类只在测试出现，报告被留出类型的二元像素级 AUROC / PRO。四轮取平均。
- 域外未见类：dacl10k 的 Cavity、Hollowareas、Weathering、Wetspot、Restformwork 等作为未见缺陷，报告二元检测指标与『未知缺陷』判定的召回。
- 对照：只用四类 max 的版本，用来证明类无关通道确实贡献了未见类型的召回。

边界与风险（需在论文中说明）：
- 干扰清单固定如下（按审核 C4，依据：不改变结构状态、巡检报告中不计为损伤）：water stain / wet patch、shadow / lighting edge、moss / biological growth（薄层）、patch repair / mortar fill、graffiti / paint、formwork texture / joint line、dirt / soot。清单在实验开始前冻结，论文附录给出定义与示例。
  - 外部集类别归属：dacl10k 的 Vegetation 与 Graffiti 在其标注中属损伤类；评估时按 dacl10k 的定义处理，即把它们计入"未见缺陷"而非干扰，并单独报告这两类，说明本方法在自建集中把薄层苔藓与涂鸦视为干扰、因而在这两类上预期召回偏低。这是定义冲突，不是模型失败，需如实写出。Wetspot 在 dacl10k 为损伤类，与本清单的 water stain 冲突，同样单列。
  - 不允许的做法：根据外部集指标回头增删干扰清单。
- 与正常库外观接近的未见缺陷（轻微渗水、浅色沉积）残差小，类无关通道会弱；这类漏检应作为失败案例分析，而非回避。

## 掩码方案定稿（用户 2026-10-29：原始分层标注保留，按同行论文做法）
同行标准：dacl10k（WACV 2024）是桥梁多损伤分割的现行基准，采用多标签语义分割：每类一张独立二值掩码，允许重叠，模型用 per-class sigmoid，指标为 per-class IoU 与 mIoU。MultiADS（ICCV 2025）在多类型异常分割上同样按缺陷类型独立输出掩码。

本数据集采用同一协议：
1. 从原始分层标注重建 4 张独立二值掩码（crack / corrosion / spalling / efflorescence），重叠处两类同时为正。保留当前拍平 RGB 图作为可视化与 S2DS 对比用。
2. 训练：per-class sigmoid，Focal + Dice 按通道独立；类无关通道目标为四类并集。
3. 评估：主表报告 per-class IoU、mIoU、像素级 AUROC / PRO、图像级 AUROC / AP；与 S2DS 对比时按 裂缝>锈蚀>剥落>泛碱 拍平后再算单标签 IoU，并写明规则。
4. 发布：随代码发布重建脚本与调色板文件，便于复现。
